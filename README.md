# zaifirstview 🚀

**3D Interactive Portfolio Website** for R. Rusaith Ahamed (Zai)

🌐 **Live:** [zaieduhub.github.io/zaifirstview](https://zaieduhub.github.io/zaifirstview)

## ✨ Features

- 🎮 Interactive 3D particle nebula background (Three.js / WebGL)
- 🔮 Floating wireframe geometric objects with mouse parallax
- ⚡ Glitch text effects & typing animation
- 🎨 Cyber-holographic glassmorphism design
- 📱 Fully responsive (mobile-first)
- 🖱️ Custom cursor with hover effects
- 📊 Animated skill circles & stats counters
- 🕐 Interactive experience timeline
- 🌊 Smooth scroll animations
- 🌟 Connection lines between particles

## 🛠️ Tech Stack

- **Vite** — Lightning fast build tool
- **Three.js** — 3D WebGL rendering
- **Vanilla JS** — No framework overhead
- **Modern CSS** — Glassmorphism, gradients, animations

## 🚀 Development

```bash
npm install
npm run dev      # Start dev server at localhost:3000
npm run build    # Production build
npm run preview  # Preview production build
```

## 📦 Deployment

Auto-deployed to GitHub Pages via GitHub Actions on push to `main`.
